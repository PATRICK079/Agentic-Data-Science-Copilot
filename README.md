# Agentic Data Science Copilot

An AI agent-powered data science workflow built with CrewAI.

This project uses a team of specialized agents to automate a regression workflow for supplement sales data. The agents plan the analysis, preprocess the dataset, train a Random Forest model, evaluate performance, and summarize feature importance.

The workflow is currently tailored to the included supplement sales dataset, but it can be extended to support other datasets by making the dataset path, target column, problem type, and preprocessing choices configurable.
